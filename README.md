## Project Overview

This project uses SQL and a relational airline database to analyze airlines, flights, airports, and bookings, with a focus on extracting meaningful business insights from operational and booking data.

## Objective

The objective of this project is to analyze airline data and generate insights related to:

- Airline Performance
- Travel Class Analysis
- Airport and Route Analysis
- Pricing Insights
- Revenue Analysis
- Business Decision-Making

## Database Tables

The project includes the following tables:

- Airlines
- Flights
- Airports
- Bookings

The tables are connected using primary keys and foreign keys to represent relationships within the airline database.

## SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- Aggregate Functions
- COUNT()
- SUM()
- AVG()
- MIN()
- MAX()
- JOIN
- LEFT JOIN
- Subqueries
- Filtering
- Sorting

## Key Business Insights

### Airline Performance

- Airline performance can be compared using booking volume and revenue.
- Booking trends help identify airlines with higher passenger demand.

### Travel Class Analysis

- Booking patterns can be compared across different travel classes.
- Revenue contribution can be evaluated across travel classes.

### Airport and Route Analysis

- Popular airports and routes can be identified using booking data.
- Route-level analysis helps understand passenger demand.

### Pricing Insights

- Flight prices can be compared across airlines, routes, and travel classes.
- Minimum, maximum, and average prices help identify pricing differences.

### Revenue Analysis

- Total revenue can be analyzed airline-wise and route-wise.
- High-revenue airlines and routes can be identified for business decision-making.

## Conclusion

This project demonstrates how SQL can be used to analyze airline data, work with relational databases, and generate meaningful business insights from bookings, routes, pricing, and revenue.
